# Privacy
- Usualy Labs collects **no** personal data: no accounts, analytics, cookies, trackers, or forms that send data to us.
- Anything you save stays in your own browser (local storage / IndexedDB). Clear it from your browser settings at any time.
- Some tools fetch public data **directly from your browser** to the publisher (e.g. a postcode sent to postcodes.io). Each tool lists these services. Those providers have their own privacy policies.
- Hosting: if you use the GitHub Pages site, GitHub may log technical data such as IP addresses as the host. See GitHub's privacy statement.
- GitHub Issues are public. Please don't post personal information in them.
