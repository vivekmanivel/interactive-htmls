1. What the terms mean

Note

A single pitch, such as C, F♯ or B♭. The piano has 12 different pitch classes before the pattern repeats in the next octave.

Root

The note a chord is named after. The root of C major is C; the root of A minor is A. The root does not have to be the lowest note in an inversion.

Chord / triad

A chord combines notes played together. A triad contains three different note names: root, third and fifth.

Major

A major triad uses a major third above the root and a perfect fifth above the root. Formula: 1–3–5. Example: C–E–G.

Minor

A minor triad uses a minor third above the root and a perfect fifth above the root. Formula: 1–♭3–5. Example: C–E♭–G.

Inversion

The same three chord notes are rearranged so a different chord tone is the lowest note. The chord quality stays the same; the voicing changes.

Major vs minor: what changes?

For a given root, the fifth usually stays the same. The third moves down by one semitone to change a major triad into a minor triad. For example, C major is C–E–G; C minor is C–E♭–G.

A semitone is the distance from one piano key to the immediately adjacent key, whether white or black. Two semitones make a whole tone.

2. How to build the chords

Major triad

0 + 4 + 7 semitones

Start on the root, go up 4 semitones for the major third, then 3 more semitones for the fifth.

Minor triad

0 + 3 + 7 semitones

Start on the root, go up 3 semitones for the minor third, then 4 more semitones for the fifth.

Three positions, one chord

Root position

Root is lowest.

C major: C – E – G

First inversion

Third is lowest.

C major: E – G – C (next octave)

Second inversion

Fifth is lowest.

C major: G – C (next octave) – E (next octave)

Important: Inversions do not create a new chord quality. C–E–G, E–G–C and G–C–E are all C major. Only the order and spacing change.

Quick piano-key reminder

The black keys are named with sharps (♯) or flats (♭). For example, C♯ and D♭ are the same physical key on a standard piano, though the correct written name depends on the chord’s spelling. This guide uses common chord spellings to keep the written notes musically correct.

4. A simple daily practice routine

  1. Choose one root. Play its major triad in root position and say each note aloud.
  2. Change to minor. Keep the root and fifth; lower the third by one semitone.
  3. Play the inversions. For each chord, play root position, first inversion, then second inversion slowly and evenly.
  4. Return to root position. Notice how the chord tones move by the smallest practical distance. This helps make chord changes smoother.
  5. Test without looking. Hide the notes, play the chord, then check the table and tick the row only if you got both the notes and position right.
  6. Review mixed roots. After practising one root, shuffle the order by choosing different roots and qualities rather than always playing C first.
