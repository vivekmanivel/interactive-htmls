# Piano 72 Chords: Chord Trees with Keyboard Positions

A free, single-file practice sheet showing every major and minor triad in every inversion (24 chords × 3 positions = 72 shapes), each drawn on a keyboard.

## What it does
- Explains where "72" comes from and the key terms (triad, root, major, minor, inversion, sharps and flats).
- Groups the 72 shapes into **12 chord trees**: each tree keeps one top note fixed while the 6 triads containing it change underneath.
- Shows every chord on a 3-octave keyboard: left-hand root in blue, right-hand triad in red, top note outlined.
- Progress tracker with a halfway marker and per-tree counts.
- Quick-reference table of all 24 chords and a practice routine.
- Theme switcher (auto, light, dark).
